# 🔥 Phoenix — Local-First Autonomous AI Agent

[![Node.js](https://img.shields.io/badge/Node.js-%3E%3D20.0.0-339933?logo=node.js&logoColor=white)](https://nodejs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-F59E0B.svg)](https://opensource.org/licenses/MIT)

**Phoenix** — это локальный автономный AI-агент с современным веб-интерфейсом в стиле **macOS Liquid Glass**, разработанный для написания кода, работы с файловой системой, безопасного выполнения терминальных команд и подключения внешних инструментов по протоколу **MCP (Model Context Protocol)**.

---

## ✨ Ключевые возможности

- **🗂 Работа с проектами и файлами (Workspace IDE)**
  - Встроенное дерево файлов, редактор кода **Monaco Editor**, предпросмотр медиафайлов и автоматическая генерация карты репозитория (**Repo Map**).
  - Мгновенный откат изменений (**Undo**), внесённых агентом, за один клик по снапшотам в базе данных.
- **🐳 Безопасный терминал и Docker Sandbox**
  - Выполнение команд внутри изолированных эфемерных контейнеров `node:20-alpine` (лимит **512 MB RAM** и **1 CPU**) через `dockerode` или прямое выполнение с жёстким таймаутом (30 сек).
  - Встроенный **Blocklist** разрушительных команд (`rm -rf /`, `format C:`, `del /f /s /q C:\*`) и кнопка **«Остановить процесс»** в реальном времени.
  - Режим **Human-in-the-Loop** (подтверждение операций записи/удаления/команд) и переключатель **Full Access**.
- **🔌 Поддержка MCP (Model Context Protocol) и веб-поиска**
  - Умная установка MCP-серверов прямо по ссылке на GitHub-репозиторий (включая монорепозитории) или через чат с агентом.
  - Встроенный бесплатный веб-поиск (**Parallel Search MCP** + нативный **Google Search Grounding** для моделей Gemini).
- **🌐 Мульти-провайдеры и удобный поиск моделей**
  - **Встроенные провайдеры**: OpenAI, OpenRouter, Google Gemini.
  - **Кастомные провайдеры**: неограниченное добавление любых OpenAI-совместимых серверов (Ollama, vLLM, LM Studio, собственный VPS) с индивидуальным управлением списком моделей.
  - Группировка моделей по провайдерам и мгновенный поиск в шапке чата.
- **🧠 Долговременная память (`memory.md`)**
  - Агент автоматически запоминает архитектурные решения, предпочтения и правила проекта.

## 🚀 Установка и быстрый старт

Запустите Phoenix одной командой без предварительной настройки (требуется **Node.js >= 20.0.0**):

```bash
npx @qzlfee/phoenix-agent
```

Для запуска на пользовательском порту:

```bash
npx phoenix-agent --port 4000
```

После старта сервер автоматически откроет локальный веб-интерфейс в браузере (по умолчанию `http://127.0.0.1:3000`).

## 🔒 Приватность и хранение данных

Phoenix спроектирован по принципу **100% Local-First**:

- Все настройки, API-ключи, история чатов, снапшоты файлов и рабочие папки проектов хранятся **исключительно локально** на вашем компьютере в директории `~/.phoenix/`:
  - `~/.phoenix/config.json` — конфигурация провайдеров и зашифрованные/локальные настройки;
  - `~/.phoenix/mcp-config.json` — конфигурация подключённых MCP-серверов;
  - `~/.phoenix/phoenix.db` — локальная база данных SQLite (чаты, сообщения, снапшоты файлов);
  - `~/.phoenix/projects/{projectId}/` — изолированные рабочие директории ваших проектов;
  - `~/.phoenix/memory.md` — глобальная долговременная память агента.
- Ваши ключи и исходный код **никогда не передаются** на сторонние серверы Phoenix — запросы отправляются напрямую с вашего компьютера только к выбранному вами LLM-провайдеру.

## 🛠 Локальная разработка

1. **Клонируйте репозиторий и установите зависимости:**

```bash
git clone https://github.com/your-username/phoenix-agent.git
cd phoenix-agent
npm install
```

2. **Соберите серверную и клиентскую части:**

```bash
npm run build
```

3. **Запустите агент локально:**

```bash
npm start
```

Для разработки фронтенда с горячей перезагрузкой (Vite HMR):

```bash
npm run dev:web
```
